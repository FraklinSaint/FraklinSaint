## Projects

### 1. FacePeak — AI facial aesthetics analysis

AI platform that analyzes facial aesthetics from a photo. It scores symmetry, proportions and harmony of facial features, shows the measurements and gives personal recommendations. Available as a web app and a Telegram bot.

- **Role:** founder and lead developer
- **What I did:** designed the product architecture, built backend integrations and the Telegram bot, implemented payment flows, data storage, rate limiting and account deletion, handled testing and deployment, made product decisions and ran marketing
- **Stack:** Python, PostgreSQL, Cloudflare R2, Railway, Vercel, Telegram Bot API, AI development tools
- **Try it:** [Telegram bot](https://t.me/FacePeakAppBot)

### 2. SafeDeal — P2P escrow on Solana

Decentralized platform for safe peer-to-peer deals. The buyer locks USDC in an escrow contract and the funds go to the seller after the deal is confirmed. In a dispute the funds stay locked according to the contract logic. Integrated with Telegram.

- **Role:** developer
- **What I did:** application architecture, Solana integration, escrow deal logic, frontend components, data storage, user profiles and ratings, Telegram integration
- **Stack:** TypeScript, Solana, Rust, Anchor Framework, React, Cloudflare D1, SQL, Vercel, Telegram Bot API
- **Try it:** [Live demo](https://safedeal-bice.vercel.app)

### 3. CONSTITUTION — safety layer for DeFi admin changes

Security protocol for Solana that protects DeFi protocols from dangerous changes to admin parameters. Critical settings changes go through a public delay, so users have time to spot risky actions before they execute. Submitted to the **Alliance accelerator**.

- **Role:** developer
- **What I did:** designed and built the on-chain security logic and the delayed-execution mechanism, added limits on vault and fund-distribution operations
- **Stack:** Rust, Solana, Anchor Framework, smart contracts
- **Try it:** [Demo and source](https://constitution-xi.vercel.app/)
